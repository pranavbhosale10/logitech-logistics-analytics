# Data

This folder contains the datasets used for the LogiTech logistics and warehousing analytics project.

The project uses three main datasets:

- Shipment Delivery Data
- Warehouse Operations Data
- Inventory Stock Movement Data

Due to file size and data-sharing considerations, the complete raw datasets are not included in this repository.

The analysis notebooks, SQL scripts, Excel dashboard, Power BI dashboards, and project documentation are provided to demonstrate the complete analytics workflow.
