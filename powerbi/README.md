# Power BI Dashboard

This section contains the Power BI analysis for the LogiTech project.

## Objective

Maximize Financial Efficiency by analyzing shipment costs, operational costs, warehouse performance, utilization, inventory turnover, and cost optimization opportunities.

## Dashboard Areas

- Executive Financial Overview
- Warehouse Performance
- Cost Optimization

## Key Analysis

- Total and average shipment cost
- Total and average operational cost
- Warehouse utilization
- Inventory turnover
- Carrier-wise cost analysis
- Delivery mode cost analysis
- Monthly shipment cost trends
- Warehouse cost comparison
- High-cost warehouse identification
