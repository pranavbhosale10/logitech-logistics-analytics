# Python Analysis

This section contains the Python-based analysis for the LogiTech project.

## Objectives

Strengthen Inventory Management through exploratory data analysis and perform statistical analysis to validate important business relationships.

## Analysis Included

- Inventory stock analysis
- Reorder-level analysis
- Stockout analysis
- Carrying cost analysis
- Warehouse-level inventory analysis
- Statistical hypothesis testing
- Correlation analysis
- Shipment cost prediction using machine learning

## Tools

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
