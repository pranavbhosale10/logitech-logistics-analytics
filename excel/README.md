# Excel Analysis

This section contains the Excel-based analysis for the LogiTech project.

## Objective

Improve Delivery Reliability and Cost Efficiency by analyzing shipment performance, delivery accuracy, damage rates, carrier performance, and shipment costs.

## Key Analysis

- Shipment volume analysis
- Carrier performance
- Shipment status distribution
- Damage analysis
- Delivery mode analysis
- Monthly shipment cost trends
- KPI analysis
- Interactive dashboard using PivotTables and slicers
